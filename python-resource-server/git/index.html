000GIT — GitHub

Repos, workflows, deploy pipelines, and agent scripts for the NZRT GitHub organisation.

Endpoints

PathDescriptionAuth
GET /app/git/search?q= Full-text search across GitHub vault x402 $0.005
GET /app/git/note?section=&file= Fetch a specific GitHub knowledge note x402 $0.005

Usage Examples

# Search GitHub vault
curl -i "https://api.nzrtnetwork.com/app/git/search?q=workflow"

# Fetch a note
curl -i "https://api.nzrtnetwork.com/app/git/note?section=01+-+Git+Fundamentals&file=00+-+Git+Overview"
